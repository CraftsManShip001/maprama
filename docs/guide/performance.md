# 성능

## 앱 코드에서 지킬 것

### 연속 값은 구독한 만큼만

엔진은 캐릭터 위치나 카메라 상태를 **구독한 경우에만** 보냅니다. 화면에 필요한 곳에서만 `useCharacterPosition` / `useCameraState`를 쓰고, `throttleMs`를 넉넉하게 주세요 (기본 250 ms). 같은 토픽은 엔진 구독 하나로 공유됩니다.

### 라벨 내용 함수는 필요할 때만 다시 평가

`labels.content` 함수는 모든 라벨에 대해 실행되지만, 새 `labelsIndex`가 올 때, `labels`의 함수가 아닌 필드가 바뀔 때, `ref.refreshLabelContent()`를 부를 때만 실행됩니다. 렌더마다 인라인 함수를 새로 만들어도 다시 계산하지 않으므로 `useCallback`은 필요 없습니다. 함수가 읽는 데이터가 바뀐 경우에만 `refreshLabelContent()`를 부르세요. [라벨](./labels#커스텀-내용)을 보세요.

### 자식 컴포넌트는 알아서 묶인다

`Character`, `CharacterLayer`, `DropLayer`, `Geofence`, `MapOverlay`의 변경은 애니메이션 프레임마다 **종류별 명령 최대 1개**로 합쳐집니다. 배열을 자주 갱신해도 괜찮지만, `getId`가 안정적인 id를 돌려줘야 diff가 작아집니다.

### 오버레이는 React 렌더 없이 움직인다

`MapOverlay`의 위치는 `Animated` 값으로 적용됩니다. 오버레이 안의 컴포넌트는 `memo`로 감싸 두면 카메라 이동 중 렌더가 0회입니다.

## 데이터 크기

| 대상 | 권장 |
| --- | --- |
| 월드 JSON | `diorama-osm`은 3 MB를 넘으면 경고합니다. 넓은 지역은 나누세요 |
| 캐릭터 모델 | `diorama optimize` 기본 예산: 삼각형 20,000개, 텍스처 1024 px |
| 압축 | Meshopt 디코더는 엔진에 들어 있습니다. Draco 압축 모델은 디코더를 `www.gstatic.com`에서 받으므로 네트워크가 필요합니다 |

`world`의 `url` 응답은 호스팅 서비스가 `ETag`와 `Cache-Control: private, max-age=86400, stale-while-revalidate=604800`으로 보내므로 재방문 때 304로 끝납니다.

## v1 웹 엔진 (WebView)

- 엔진은 약 900 KiB짜리 인라인 HTML(`engine.html`) 하나로 WebView에 들어갑니다. 따로 내려받는 엔진 파일은 없습니다.
- WebView는 투명·비스크롤로 렌더링되고, 메시지는 문자열 봉투(`{"v":1,"seq":N,"kind":"cmd"|"evt","msg":…}`)로 오갑니다. 큰 월드를 `data`로 인라인하면 이 문자열이 커지므로 `url`을 권장합니다.
- 월드가 로드되기 전에 보낸 캐릭터, 드롭, 지오펜스는 엔진이 보관했다가 적용하므로 `onReady`를 기다렸다가 자식 컴포넌트를 렌더링할 필요가 없습니다.
- Android 렌더 프로세스가 죽거나 iOS 콘텐츠 프로세스가 종료되면 WebView를 다시 만들거나 새로고침하고, `init`과 모든 선언형 상태를 다시 보냅니다. 진행 중인 `travel`은 `engine_reloaded`로 reject됩니다.
- 기기의 "동작 줄이기" 설정(`prefers-reduced-motion`)을 따라 카메라 애니메이션을 줄입니다.

## v2 네이티브 엔진 예산

기준 기기(iPhone 12 / Pixel 6a급)에서 성수 샘플을 건물 20,000동으로 늘린 장면의 **목표치**입니다. 모두 M4에서 측정하기 전의 추정이고, 실측이 생기면 CI 성능 게이트로 바뀝니다.

| 항목 | 목표 |
| --- | --- |
| 프레임 | 60 fps에서 16.6 ms (p95). 코어 틱 ≤ 2 ms, 디오라마 인코딩 ≤ 4 ms, MapLibre 베이스맵 ≤ 5 ms |
| 네이티브 힙 | 엔진 전체 ≤ 250 MB (타일 캐시 50 MB, 디오라마 지오메트리 ≤ 60 MB, 텍스처 ≤ 64 MB, 캐릭터당 ≤ 8 MB) |
| 드로 콜 | 프레임당 ≤ 150 (건물 256 m 셀 청크, 드롭은 종류 × 희귀도당 1, 라벨 ≤ 3) |
| 캐릭터 | 스키닝 ≤ 32명, 캐릭터당 관절 ≤ 64 |
| 드롭 | 활성 ≤ 5,000, 화면 ≤ 1,500 |
| 라벨 | 인덱스 ≤ 1,000, 프레임당 배치 ≤ 300 |
| 메시지 디코드 | 일반 명령 ≤ 0.2 ms, 5 MB 인라인 월드 `init` ≤ 150 ms (워커, p95) |
| 지연 | JS `send` → 적용 ≤ 1 프레임, 이벤트 → JS 핸들러 ≤ 1 프레임 |
| 콜드 스타트 | 뷰 마운트 → `ready` ≤ 300 ms, `init` → 첫 디오라마 프레임 ≤ 1 s |
| 바이너리 | ABI당 +12 MB 이하 (에셋 제외) |
| 배터리 | `device` 위치 소스 포그라운드 추가 소모 ≤ 5 %/h |
