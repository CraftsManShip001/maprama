프리셋으로 시작하고, 필요한 것만 바꾼다

지도 외관은 테마 하나로 정해집니다. 기존 리얼·토이·미니멀은 그대로 두고, 깔끔하고 모던한 게임 감성의 모던 프리셋, 유리·금속·콘크리트로만 이루어진 도심 프리셋과 시네마틱 색보정, 다양한 건물 매스, 도로·거리 옵션을 새 선택지로 추가했어요. 앱은 프리셋을 고른 뒤 필요한 값만 덮어씁니다.

진짜 GPS로 걷고, 목적지를 주면 알아서 간다

실제 GPS 신호는 수십 미터씩 튀고 끊깁니다. SDK가 튀는 값을 버리고 흔들림을 걸러낸 뒤 도로 위로 붙여서, 캐릭터가 건물을 뚫지 않고 걷게 합니다. 목적지를 주면 기기 안의 도로 그래프로 경로를 찾고, 이동 수단마다 속도·모델·애니메이션을 바꿔 이동합니다.

좌표에 떨어뜨리고, 가까이 가면 줍는다

드롭 모델과 연출은 앱이 정하고, 배치·등장 연출·수집 판정은 SDK가 맡습니다. 음악 드롭(CD·LP·음표)을 새 선택지로 추가했어요. 희귀도에 따라 빛기둥 색이 달라지고, 주우면 곡 카드와 효과음이 나옵니다. 멀리 있는 아이템을 탭하면 그곳까지 걸어갑니다.

다른 플레이어는 부드럽게, 건물 뒤에선 실루엣으로

앱의 서버에서 띄엄띄엄 오는 위치를 SDK가 버퍼링해 보간하므로 캐릭터가 순간이동하지 않습니다. 건물 뒤로 들어간 캐릭터는 건물과 깊이 정보를 공유해 실루엣으로 비칩니다. 폰 화면을 돌려 건물 뒤에 선 캐릭터를 찾아보세요.

구역에 들어가면 건물이 반응한다

광장 둘레 60m를 지오펜스로 지정했습니다. 캐릭터가 들어가면 입장 이벤트가 오고, 이 예시에서는 광장 타워 상태를 captured로 바꿔 깃발과 빛나는 효과를 켭니다. GPS 모드에서도 경로가 광장을 지나가요.

건물 하나하나를 코드로 꾸민다

건물 ID로 색·지붕·외벽·데코를 바꾸거나, 직접 만든 glTF 모델로 통째로 교체하고, 게임 상태에 따라 외관을 바꿀 수 있습니다. 벡터 타일 경계에서 잘린 건물 조각은 SDK가 하나로 다시 합쳐 같은 ID로 다룹니다.

라벨 스타일 비교: 미니멀+ · 홀로그램 표지판

홀로그램 표지판 아이콘을 흰색·검은색 타일 + 라인 아이콘 세트로 바꿨어요. 아래 아이콘 시트에서 12종 전체를 볼 수 있고, 스타일 탭의 "표지판 아이콘"에서 자동·화이트·블랙·컬러(기존)를, "표지판 내용"에서 이름+종류·이름만·텍스트만·커스텀을 고를 수 있어요.

같은 장면(실제 동네형 · 도심 · 게임 뷰 유지)에서 새로 만든 두 스타일을 찍었어요. 버튼을 누르면 위 폰 화면에 바로 적용되고, 홀로그램은 화면을 이동하거나 줌할 때 패널이 떠오르고 사라지는 움직임까지 볼 수 있어요.

MVP까지 네 단계

앞 단계가 끝나야 다음 단계를 시험할 수 있는 순서입니다. 완료 기준의 숫자는 제안하는 목표치예요.

  1. M1

    건물이 서 있는 지도

    • 포크 빌드 파이프라인 (iOS · Android)
    • 테마 시스템 · 리얼 외벽 · 그림자
    • 카메라 0–60° · 회전
    • 건물 ID 조회 · 탭 선택

    완료 기준 실제 동네 건물 2천 동을 중급 안드로이드 기기에서 60fps

  2. M2

    걸어 다니는 캐릭터

    • glTF 로딩 · 걷기/달리기 블렌딩
    • GPS 보정 · 도로 매칭
    • 경로 탐색 · 도보/자전거/자동차/혼합
    • 건물 뒤 실루엣

    완료 기준 실제로 동네를 걸을 때 캐릭터가 건물을 뚫거나 순간이동하지 않음

  3. M3

    게임 요소

    • 드롭 · 수집 콜백
    • 지오펜스 입장/퇴장
    • 다른 플레이어 보간 동기화
    • 이벤트 API 정리

    완료 기준 캐릭터 50명 + 아이템 500개 동시 표시

  4. M4

    건물 꾸미기와 배포

    • 토이 · 미니멀 프리셋 · 시간대
    • 색 · 지붕 · 데코 · 랜드마크 교체 · 상태 규칙
    • SPM · Maven 배포
    • 오픈소스 고지 자동 생성

    완료 기준 샘플 게임 앱이 SDK만으로 이 미리보기 화면을 재현

확정한 결정과 그 영향

결정들이 SDK 범위와 저장소 구성을 어떻게 바꾸는지 정리했습니다.

  • 스타일 · 리얼 기본, 테마로 지정외벽은 텍스처 아틀라스 하나에 유리 커튼월·사무동·아파트·벽돌 저층을 담고, 건물 높이·용도 태그로 자동 선택합니다. 앱은 프리셋을 고른 뒤 필요한 값만 덮어쓰고, 조건별 규칙으로 특정 건물만 바꿀 수 있어요.
  • 건물 데이터 · OSM + 국내 보강OSM에 국가공간정보포털 GIS건물통합정보의 높이·층수를 붙이는 타일 빌드 도구(예: Planetiler 기반)가 저장소에 들어갑니다. 공공데이터 이용 조건과 OSM(ODbL) 출처 표기를 문서에 명시해야 해요.
  • 경로 탐색 · 기기 안에서 계산타일에 도로 그래프 레이어를 함께 넣고, 경로 탐색과 GPS 도로 매칭이 같은 그래프를 씁니다. 서버가 없어 오프라인에서도 동작하고, 도보·자전거·자동차 거리 범위에 집중합니다.
  • 멀티플레이 · 클라이언트 보간만SDK는 위치 스냅샷을 받아 보간·예측·실루엣까지만 담당합니다. Firebase든 자체 서버든 앱이 고르고, 샘플 앱에 가짜 스트림 예제만 둡니다.
  • 배포 · 완전 오픈소스MapLibre(BSD-2)와 호환되는 BSD-2 또는 Apache-2.0으로 공개합니다. 유료 타일 서버가 없으니 누구나 타일을 직접 만들 수 있는 빌드 스크립트와 샘플 지역 타일이 필수예요.
  • 음악 드롭 · 앱이 곡을 정하고 SDK가 연출드롭은 모델·곡 데이터(payload)·희귀도만 받고, 떨어지는 연출·빛기둥·파티클·수집 판정은 SDK가 처리합니다. 곡 카드나 재생은 앱의 UI로 연결해요.
  • 도로 · 앱이 표시 여부를 지정차선·횡단보도·거리 소품·주변 교통을 테마에서 각각 켜고 끌 수 있고, 프리셋마다 기본값만 다릅니다.

다음 단계는 저장소 구조와 M1(건물이 서 있는 지도) 작업 계획입니다.
